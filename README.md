# Homebrew tap for Flovr

[Flovr](https://github.com/flovrlabs/flovr) runs AI workflows written as YAML files in git, with tests that call the models.

```bash
brew install flovrlabs/tap/flovr
```

`Casks/flovr.rb` is written by each release of Flovr, so it is not edited by hand here. Bugs and questions go to [flovrlabs/flovr](https://github.com/flovrlabs/flovr/issues).
